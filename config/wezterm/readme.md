Kubuntu（KDE Plasma）なら、Super + 右ドラッグでWezTermのウィンドウサイズを自由に変更できる。
- Super + 左ドラッグ → ウィンドウ移動
- Super + 右ドラッグ → ウィンドウサイズ変更
WezTermの端や角を正確につかむ必要がないので、かなり使いやすい。
なお、今のWezTerm設定で

```lua
config.window_decorations = "TITLE | RESIZE"
```

としているなら、通常どおりウィンドウの端や角をドラッグしてリサイズすることも可能である。
KDEでは Super + 左/右ドラッグ をセットで覚えるのがおすすめである。
